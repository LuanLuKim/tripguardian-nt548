## 5. Môi trường máy của chủ dự án (Windows)

- `gh` active là **LuanLuKim**. `git push` mặc định dùng credential của LuKimLuan-UIT nên bị 403. Push bằng `git -c credential.helper= -c "credential.helper=!gh auth git-credential" push`.
- **Merge:** agent chỉ đẩy nhánh và mở PR, chỉ merge khi chủ dự án nói rõ PR nào.
- **Python:**
  - `.venv` (Windows) đủ cho editor và lint, nhưng **không chạy được `corpus.index`** (cần `fcntl`).
  - Chạy pipeline và test trong **WSL Ubuntu**: venv `~/.venvs/tripguardian-nt548` (Python 3.12, `uv`); thư mục làm việc `~/nt548-work` (không dùng `/tmp`, vì WSL tắt distro thì `/tmp` mất).
- **Postgres trên máy này:** Docker Desktop thường tắt.
  - Dùng `pgserver` (pip) trong venv WSL, dữ liệu ở `~/nt548-work/pg`.
  - `pgserver` thiếu `citext`, nên trong venv đã thêm một `citext` giả (domain trên `text`), chỉ đủ để thử. CI dùng `postgres:16` thật.
- Harness nạp `.env` ở gốc repo. Chạy harness thật trên máy thì chạy từ bản chép không có `.env` (ví dụ `~/nt548-work/tg`), để không dùng key thật.
- File chưa commit, **không đưa lên repo**: `docs/nt548-HANDOFF-backup-2026-11-20.md`, `docs/nt548/LEARN-ops-code.md`.
