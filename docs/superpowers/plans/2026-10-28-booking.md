# Kế hoạch: `booking` + `journey` (B.6, §1 mục 12)

Spec: `docs/superpowers/specs/2026-10-26-production-and-course-upgrade-design.md` §B.6. Plan làm việc, tạm thời (`RULE.md` §0.1).

## Quyết định

- Hai module online mới, mỗi cái một thư mục: `src/booking/` (Offer + deeplink, mỗi nhà cung cấp một adapter) và `src/journey/` (đường nhà → chỗ ở, code quyết phương án nào khả thi). `journey` gọi `booking` và `live` chỉ qua `__init__.py`.
- `Offer` chỉ mang điều link nói được hợp lệ. Giá / giờ không đọc được → `None` (unknown), không suy ra. Chuyến bay chỉ là link Google Flights điền sẵn (không gọi `live.flights`, không Playwright).
- Nguồn dữ liệu: xe khách = `live.buses` / `live.buses_url`; máy bay = `live.flights_url`; chỗ ở = `corpus.serving.stay_prices.load` (đọc file đã publish, không crawl lại). Chỗ ở chưa có giá → không có offer.
- `mode = deeplink`. Mã affiliate: `config/booking.yaml` khai tên tham số + tên biến `.env`; thiếu một trong hai thì không gắn. Adapter `api` / `book()` chưa viết (spec: chỉ có ở adapter `api`).
- Click ghi `booking_click {offer_id, provider, kind}` (web gửi qua `/api/harness/events`, `journey_id` nằm ở envelope). URL do server dựng, client chỉ mở `offer.url`.
- API tối thiểu cho UI: `GET /api/harness/booking/offers`, `GET /api/harness/journey` (đọc, không ghi trạng thái). Ghi `inbound/outbound` vẫn qua `pick_transit` (việc UI, ghi ở ledger).
